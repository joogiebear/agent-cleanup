Fonts bundled into the app:

- Inter 4.1 (Regular, Medium, SemiBold; Latin subset converted to TTF, all three named family "Inter" with weights 400/500/600 so `font_weight` picks them), SIL Open Font License 1.1, see Inter-LICENSE.txt. https://rsms.me/inter/

Icons come from Lucide via gpui-kit-assets; see `src/ui/assets.rs` to add one.
